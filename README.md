## Selected work

### [Calendar MCP](https://github.com/deciduus/calendar-mcp)
A Python MCP server for Google Calendar, with multi-account support, saved working hours, focus-time planning, conflict detection, and time audits. Available as `calendar-mcp-server`; [v1.1.0](https://github.com/deciduus/calendar-mcp/releases/tag/v1.1.0) includes 23 tools.

[Setup and usage](https://github.com/deciduus/calendar-mcp#quick-start)

### [Ergod](https://ergod.dev)
An AI agent that works with tools, code, files, and memory, on your own or with other people.

[Try Ergod](https://app.ergod.dev) · [Documentation](https://ergod.dev/docs.html)
